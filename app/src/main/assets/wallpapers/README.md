# Carpeta de Fondos de Pantalla (Wallpapers)

Coloca aquí cualquier archivo de imagen (.jpg, .jpeg, .png, .webp).
La aplicación escanea automáticamente esta carpeta en tiempo de ejecución:
- Reconoce de forma dinámica todos los archivos de imagen presentes sin necesidad de modificar código.
- Genera nombres presentables automáticamente a partir del nombre del archivo.
- Los muestra en la bandeja flotante accesible desde la bandeja lateral ("Cambiar Fondo de Pantalla").
- El fondo seleccionado se guarda de forma permanente y se aplica como fondo general de toda la aplicación.
