# Carpeta de Fondo de Pantalla del Proyecto (Wallpaper)

Esta carpeta (`app/src/main/assets/wallpaper/`) contiene la imagen que la aplicación utiliza como fondo de pantalla general.

Formatos soportados:
- `.jpg` / `.jpeg`
- `.png`
- `.webp`

## ¿Cómo cambiar el fondo de pantalla?
Reemplaza el archivo `wallpaper.jpg` (o coloca cualquier imagen `.jpg`, `.png` o `.webp` en esta carpeta). La aplicación detectará automáticamente el archivo y lo aplicará como fondo principal en la próxima actualización o compilación.
